Privacy Policy – Terra Wild Nature Uploader

Last updated: 2 November 2026

Terra Wild Nature Uploader ("the app") is an internal tool used solely by the owner of the Terra Wild Nature YouTube channel to upload the channel's own videos. The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service.

Information accessed

With the channel owner's authorization (OAuth), the app accesses only the channel owner's own YouTube account in order to upload videos, set thumbnails and edit video titles and descriptions. The app does not access, collect or store data about any other YouTube users.

Use and storage

The OAuth refresh token is stored encrypted as a private secret in the owner's GitHub repository settings and is used only to perform uploads to the owner's channel. No personal data is sold, shared with third parties or used for advertising.

Google Privacy Policy

Data processed through YouTube API Services is also subject to the Google Privacy Policy.

Data deletion

The app does not store any YouTube API Data. The only stored item is the OAuth refresh token. The channel owner can delete it at any time by revoking access (see below) and removing the secret from the GitHub repository; it is deleted immediately. Any cached YouTube API Data would be deleted within 30 days at most, as required by the YouTube API Services Developer Policies.

Revoking access

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions. Revoking access deletes the app's ability to use the stored token.
